# Cườngnèhihii · Sổ tay ghi chú

Bản web tĩnh của ứng dụng ghi chú lỗi phần mềm. Dữ liệu được lưu trên trình duyệt (`localStorage`), có nút xuất/nhập để sao lưu.

- Không có phần AI.
- Có nút **Sửa** ở thanh công cụ chi tiết và ở mỗi thẻ ghi chú.
- Giao diện tối ưu cho máy tính và điện thoại.
